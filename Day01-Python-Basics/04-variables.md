Variables are named containers used to store data values in system memory. 
* **Dynamic Typing:** Python automatically detects the data type based on the value assigned. You do not need to explicitly declare the type.
* **Re-assignment:** Variables can change their stored value or even their data type dynamically during runtime.
</details>

```python
# Assigning values to variables
age = 36          # Stored as Integer
gpa = 3.44        # Stored as Float
user_name = "Raja" # Stored as String
is_active = True   # Stored as Boolean

# Practicing Dynamic Re-assignment
```
