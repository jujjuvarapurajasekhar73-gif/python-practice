# ⚡ Escape Sequences in Python

<details open>
<summary><kbd> 📝 Click to Toggle: Notes & Explanation </kbd></summary>
<br>

Escape sequences are special characters preceded by a backslash (`\`) used to format strings and insert characters that are otherwise difficult to type.
* `\n`: Inserts a new line, shifting the subsequent text to the next line.
* `\t`: Inserts a horizontal tab space (equal to 4 standard spaces).
* `\'` and `\"`: Allows you to include single or double quotes inside a string without breaking it.
</details>

<details open>
<summary><kbd> 💻 Click to Toggle: Code Practice </kbd></summary>
<br>

```python
# Using \n for a new line
print("Hello\nMama")

# Using \t for tab spacing
print("Name:\tRajasekhar")

# Including quotes within a string
print("Welcome to \'Python\' Practice")
print("He said, \"Keep coding daily!\"")
```
