# ⚙️ How Python Code is Executed

<details open>
<summary><kbd> 📝 Click to Toggle: Notes & Explanation </kbd></summary>
<br>

Python is often called an interpreted language, but it follows a two-step translation process behind the scenes:
1. **Source Code (.py):** The raw human-readable code written by the developer.
2. **Compilation Phase:** The Python compiler automatically scans the syntax and translates the source code into an intermediate format called **Bytecode (.pyc)**.
3. **Interpretation Phase (PVM):** The **Python Virtual Machine (PVM)** interprets the bytecode line-by-line and converts it into native **Machine Code (0s & 1s)** which the computer's CPU executes directly.
