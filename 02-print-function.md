# 🖨️ Print Function in Python

<details open>
<summary><kbd> 📝 Click to Toggle: Notes & Explanation </kbd></summary>
<br>

The `print()` function is used to display output on the screen. It can accept multiple arguments and has special parameters to format the output.
* **Multiple Values:** You can print multiple items by separating them with commas (`,`).
* **sep parameter:** Specifies the separator string inserted between values. The default is a space.
* **end parameter:** Specifies what to print at the very end of the line. The default is a newline character (`\n`).
</details>

<details open>
<summary><kbd> 💻 Click to Toggle: Code Practice </kbd></summary>
<br>

```python
# Basic Print statement
print("Hello World!")

# Printing multiple values together
print("Name:", "Rajasekhar", "Role:", "Data Analyst")

# Customizing the separator using 'sep'
print("Apple", "Banana", "Orange", sep=" - ")

# Overriding the default newline using 'end'
print("Hello", end=" ")
print("Mama!")
```
</details>
